One-star review of Monday as if Monday were a restaurant. The program writes
one line to `/output/entry.txt`:

> Waiter Monday took my weekend order, brought back an alarm clock.

Run it with Node 22 or later:

```sh
node main.ts
```

The program checks the competition gate itself before writing (1–180
characters, at most 25 words, one line, not only whitespace) and fails loudly
if the line ever violates it.

Entry for the [One Star for Monday](https://make.fun/c/u-clever-harbor-75-one-star-for-monday-9ead4a61)
competition on make.fun.
